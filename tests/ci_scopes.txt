# Required tests that a pull request runs only when it touches what they cover (tests/ci_select.sh). They stay in
# tests/ci_manifest.txt, so the nightly and manual runs always run them. Columns: file | paths (space-separated,
# * matches anything). A test also runs when its own file changes.
#
# The rule that keeps this safe: a scoped test is skipped only when EVERY changed file is "known" (in this
# file's paths or in NEUTRAL below). One change to shared code (scripts/game.gd, scripts/player.gd, items, saving,
# menus, project.godot, scenes, the workflows, ...) is not known, so the whole required list runs.
# A test that loads scenes/main.tscn depends on game.gd, so such a test is only worth scoping when its feature
# lives in its own files, as the house, workshop and launcher features do.
#
# NEUTRAL (never forces the full list, never selects a test by itself): scripts/lang/*, levels/*, assets/*,
# shaders/*, docs, balance, *.md, patch note fragments. The always-required tests (letters, texts, shaders,
# map checks, fixed window sizes, ...) still cover these.
#
